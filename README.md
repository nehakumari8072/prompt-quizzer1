# Prompt Quizzer – A Quiz Game

A simple JavaScript quiz game that runs in the browser console.

## Features
- 5 questions stored in an array of objects
- Uses a for loop, prompt() and alert()
- Answers are compared using toLowerCase() and trim()
- Immediate feedback after each answer
- Final score shown at the end

## How to Run
1. Open any browser and press F12 to open Developer Tools.
2. Go to the Console tab.
3. Copy the code from quiz.js and paste it in the console.
4. Press Enter and answer the prompts.

## Concepts Used
Arrays, objects, loops, conditionals, functions, string methods, prompt/alert.
